# LLM Agent Research Wiki

本專案是一個以 LLM Agent 研究論文為主題的 LLM Wiki，參考 Karpathy 的 LLM Wiki 知識整理方式，透過 Markdown 建立可持續更新、查詢及整合的研究知識庫。

## Project Overview

本 Wiki 以五篇 LLM Agent 相關論文為起始資料，整理 Agent 的推理、工具使用、反思、技能累積及軟體工程能力，並建立論文與概念之間的連結。

## Papers

- ReAct

- SWE-agent

## Wiki Structure

- `wiki/papers/`：論文研究筆記
- `wiki/concepts/`：LLM Agent 相關概念
- `wiki/synthesis/`：跨論文整合與比較
- `wiki/index.md`：知識庫索引
- `wiki/log.md`：操作紀錄
- `workflow/`：流程設計、檢查與驗證
- `slides/`：教學 HTML 簡報

## Workflow

Ingest → Extract → Check → Integrate → Query → Synthesis → Generate → Lint

透過反覆讀取資料、整理內容、核對來源及修正結果，逐步建立與維護研究知識庫。

## Teaching Slides

本專案預計使用 Wiki 中的內容製作 LLM Agent 初學者教學 HTML 簡報。
