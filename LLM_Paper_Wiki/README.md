# LLM Agent 論文研究 Wiki

本庫參考 Karpathy 的 LLM Wiki：Raw Sources → Persistent Wiki → Schema，並採用 Ingest / Query / Lint 工作流程。主題聚焦 LLM Agent 的推理、工具使用、反思與自主探索。

## 使用
1. 解壓縮後，可直接用 Obsidian 開啟此資料夾（Open folder as vault）。
2. 在 `raw/papers/` 放入原始 PDF（此範例以公開論文連結和初始筆記起步；PDF尚未附入）。
3. 使用 Agent 依 `AGENTS.md` 的規範進行 ingest。
4. 開啟 `slides/agent_intro.html` 瀏覽教學簡報。
5. 查看 `workflow/` 中的流程設計、檢查紀錄與反思範例。
