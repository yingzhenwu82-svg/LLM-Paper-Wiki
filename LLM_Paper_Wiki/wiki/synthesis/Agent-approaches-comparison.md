# Initial synthesis: Agent approaches

| Paper | Main focus | Loop / mechanism | Knowledge accumulation |
|---|---|---|---|
| [[../papers/ReAct]] | Reasoning grounded in action | Thought–Action–Observation | Context within task loop |
| [[../papers/Toolformer]] | Learning selective tool use | Model-generated API call insertion/training | Training-time learned tool behavior |
| [[../papers/Reflexion]] | Learning from trial feedback | Reflection and episodic memory | Reflection memory |
| [[../papers/Voyager]] | Open-ended exploration | Curriculum, feedback, skill library | Reusable skill programs |
| [[../papers/SWE-agent]] | Software task interface | Agent interacts through ACI | Task state / tool interaction |

## Synthesis (interpretive)
These approaches address different parts of agent design rather than being a single progression: ReAct emphasizes interaction pattern, Toolformer training for tool invocation, Reflexion feedback-driven reflection, Voyager open-ended skill accumulation, and SWE-agent interface design. This synthesis is interpretive and should be checked against the full papers.
