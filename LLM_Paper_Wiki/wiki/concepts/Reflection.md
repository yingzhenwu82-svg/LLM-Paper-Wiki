# Reflection
Reflection is a mechanism by which an agent analyzes feedback or previous attempts and records useful guidance for later attempts.

## Typical cycle
Attempt → Feedback → Reflection → Memory → Retry

Reflection should be grounded in actual feedback; it can be wrong or unhelpful and should be evaluated.
