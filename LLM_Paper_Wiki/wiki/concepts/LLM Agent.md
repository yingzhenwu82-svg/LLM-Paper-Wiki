# LLM Agent
An LLM Agent is a system that uses a language model to select or plan steps and interact with a task environment, often with tools, observations, and iterative execution.

## Common elements
- Model: generates plans, actions, or text.
- Tools: interfaces for external capabilities.
- Environment: task or state the agent interacts with.
- Observation: results returned after an action.
- Loop: repeats until a goal, stop condition, or failure.
